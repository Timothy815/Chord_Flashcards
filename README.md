# Fretboard Recall

Practice identifying CAGED major chord shapes, roots, inversions, and notes from guitar fretboard diagrams. The deck contains 120 cards in standard tuning. Saved practice sets stay in the browser where you create them.

## Answer modes and scoring

Choose **Multiple choice**, **Type answers**, or **Flip cards and self-score** under **Answer mode**, then select **Start practice**.

In graded modes, you earn one point for a card when every prompt on that card is correct. Skipped cards are counted separately. Missed cards can be retried in a separate round. Typed note answers accept enharmonic equivalents such as C# and Db.

## Publish on GitHub Pages

1. Create a repository on GitHub. A public repository supports GitHub Pages on GitHub Free.
2. Extract the ZIP and upload `index.html`, `style.css`, `app.js`, and this README to the repository root using **Add file → Upload files**. Commit the files.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose `main` (or the branch containing the files) and `/(root)`, then click **Save**.
5. Once GitHub finishes publishing, open the link shown under **Settings → Pages**.

The app uses plain HTML, CSS, and JavaScript. Visitors can use the GitHub Pages copy without signing into ChatGPT. Browser storage is tied to the site's address, so presets saved on another hosted copy do not transfer automatically.
